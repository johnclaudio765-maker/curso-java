Módulo V

Vetores (Arrays) e Matrizes

E se precisarmos guardar 50 notas de alunos ou representar um tabuleiro de jogo da velha? Em vez de criar 50 variáveis soltas, usamos vetores e matrizes para organizar coleções homogêneas na memória.

Atenção: Este módulo contém 10 questões ao final (8 objetivas e 2 práticas de código).
1. Vetores (Arrays Unidimensionais)

Um vetor é uma sequência indexada de posições do mesmo tipo. Em Java, a contagem dos índices sempre começa no 0 e vai até tamanho - 1.

ExemploVetor.javaDeclaração e Percurso
String[] linguagens = {"Java", "Python", "C#", "JavaScript"};

for (int i = 0; i < linguagens.length; i++) {
    System.out.println("Posição " + i + ": " + linguagens[i]);
}
2. Matrizes (Arrays Bidimensionais)

Uma matriz funciona como uma tabela com linhas e colunas, percorrida normalmente com dois laços for aninhados.

ExemploMatriz.javaMatriz 2x2
int[][] matriz = {
    {1, 2},
    {3, 4}
};

for (int linha = 0; linha < 2; linha++) {
    for (int col = 0; col < 2; col++) {
        System.out.print(matriz[linha][col] + " ");
    }
    System.out.println();
}

Questão 09 • Prática Escreva um programa Java completo chamado MediaVetor que crie um vetor de 5 números decimais (double), leia os 5 valores via Scanner, calcule e imprima a média deles.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class MediaVetor {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        double[] valores = new double[5];
        double soma = 0;

        for (int i = 0; i < valores.length; i++) {
            System.out.print("Digite o valor " + (i + 1) + ": ");
            valores[i] = sc.nextDouble();
            soma += valores[i];
        }

        double media = soma / valores.length;
        System.out.println("Média dos valores: " + media);
        sc.close();
    }
}
Questão 10 • Prática Escreva um programa Java completo chamado MaiorElemento que preencha um vetor de 6 números inteiros digitados pelo usuário e, ao final, encontre e exiba qual foi o maior número digitado.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class MaiorElemento {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int[] numeros = new int[6];

        for (int i = 0; i < numeros.length; i++) {
            System.out.print("Digite o número " + (i + 1) + ": ");
            numeros[i] = sc.nextInt();
        }

        int maior = numeros[0];
        for (int i = 1; i < numeros.length; i++) {
            if (numeros[i] > maior) {
                maior = numeros[i];
            }
        }

        System.out.println("O maior número digitado foi: " + maior);
        sc.close();
    }
}
