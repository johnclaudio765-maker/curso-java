Módulo I

Fundamentos de Lógica e Ambiente Java

Neste primeiro passo da nossa jornada, vamos desmistificar o que é programar, entender como o computador interpreta nossas instruções e conhecer a arquitetura que torna o Java famoso pelo lema: "Escreva uma vez, execute em qualquer lugar".

Atenção: Este módulo contém 10 questões ao final (8 objetivas e 2 práticas de código).
1. O que é Lógica de Programação e Algoritmo?

Pense em uma receita de bolo ou no passo a passo para trocar um pneu furado. Quando você organiza ações em uma sequência lógica para atingir um objetivo, você está criando um algoritmo.

Na computação, um algoritmo segue três etapas clássicas conhecidas como E-P-S:

  • Entrada: Os dados que o programa recebe (ex.: dois números digitados pelo usuário).
  • Processamento: O cálculo ou transformação feita sobre esses dados (ex.: somar os dois números).
  • Saída: O resultado apresentado ao usuário (ex.: mostrar o total na tela).
2. Como o Java Funciona: JDK, JRE e JVM

Diferente de linguagens que geram código preso a um único sistema operacional, o Java compila seu código-fonte (.java) para um formato intermediário chamado Bytecode (.class).

Tabela 2 — Componentes do Ecossistema Java
Sigla Nome Completo Função Principal
JVM Java Virtual Machine Máquina virtual que lê o bytecode (.class) e o traduz para o sistema operacional onde está rodando.
JRE Java Runtime Environment Ambiente de execução composto pela JVM + bibliotecas padrão necessárias para rodar programas Java.
JDK Java Development Kit Kit completo para desenvolvedores: contém a JRE + o compilador (javac) e ferramentas de criação.
3. Seu Primeiro Programa em Java

Todo código em Java vive dentro de uma classe, e o nome do arquivo deve ser idêntico ao nome da classe pública (respeitando letras maiúsculas e minúsculas).

HelloWorld.javaPrimeiro Exemplo
public class HelloWorld {
    public static void main(String[] args) {
        // Exibe uma mensagem no console e quebra a linha
        System.out.println("Olá, Mundo! Bem-vindo ao Java!");
    }
}
Dica do Professor: Java é case-sensitive (diferencia maiúsculas de minúsculas). Escrever system.out.println com "s" minúsculo causará erro de compilação!

Questão 09 • Prática Escreva um programa Java completo chamado BoasVindas que exiba no console o seu nome na primeira linha e a frase 'Estou aprendendo Java!' na segunda linha.
Sugestão de implementação em Java:
Solução ExemploJava
public class BoasVindas {
    public static void main(String[] args) {
        System.out.println("Olá, eu sou estudante de Java!");
        System.out.println("Estou aprendendo Java!");
    }
}
Questão 10 • Prática Escreva um programa Java completo chamado CartaoApresentacao que exiba uma moldura simples feita com asteriscos (***) e, dentro dela, o nome do curso e o ano atual.
Sugestão de implementação em Java:
Solução ExemploJava
public class CartaoApresentacao {
    public static void main(String[] args) {
        System.out.println("******************************");
        System.out.println("* Curso: Java Básico         *");
        System.out.println("* Ano: 2026                  *");
        System.out.println("******************************");
    }
}
