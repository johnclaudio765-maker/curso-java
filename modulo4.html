Módulo IV

Estruturas de Repetição (Laços)

Computadores são imbatíveis em tarefas repetitivas. Neste módulo, vamos aprender a repetir blocos de código usando while, do-while e for, evitando duplicação e automatizando cálculos.

Atenção: Este módulo contém 10 questões ao final (8 objetivas e 2 práticas de código).
1. Os Três Laços do Java
Tabela 4 — Comparativo das Estruturas de Repetição
Estrutura Teste da Condição Quando Usar
while No início (antes de entrar) Quando não sabemos quantas vezes vai repetir (ex.: ler até digitar sair).
do-while No final (após executar) Quando o bloco precisa rodar pelo menos 1 vez (ex.: exibir um menu).
for No início, com contador integrado Quando sabemos o início, o fim e o passo da contagem.
ExemplosLacos.javawhile e for
// Contagem regressiva com while
int contador = 3;
while (contador > 0) {
    System.out.println("Contando: " + contador);
    contador--;
}

// Contagem progressiva com for
for (int i = 1; i <= 5; i++) {
    System.out.println("Passo " + i);
}

Questão 09 • Prática Escreva um programa Java completo chamado Tabuada que leia um número inteiro digitado pelo usuário e imprima a tabuada desse número de 1 a 10 utilizando um laço for.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class Tabuada {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Digite um número para ver a tabuada: ");
        int num = sc.nextInt();

        for (int i = 1; i <= 10; i++) {
            System.out.println(num + " x " + i + " = " + (num * i));
        }

        sc.close();
    }
}
Questão 10 • Prática Escreva um programa Java completo chamado SomaAteZero que leia números inteiros continuamente usando while até que o usuário digite 0. Ao final, exiba a soma total de todos os números digitados.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class SomaAteZero {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int soma = 0;
        int numero;

        System.out.print("Digite um número (0 para sair): ");
        numero = sc.nextInt();

        while (numero != 0) {
            soma += numero;
            System.out.print("Digite outro número (0 para sair): ");
            numero = sc.nextInt();
        }

        System.out.println("Soma total: " + soma);
        sc.close();
    }
}
