Módulo VI

Métodos (Funções) e Modularização

À medida que nossos programas crescem, colocar tudo dentro do main torna o código confuso. Neste módulo, aprenderemos a dividir problemas grandes em pequenas peças reutilizáveis chamadas métodos.

Atenção: Este módulo contém 10 questões ao final (8 objetivas e 2 práticas de código).
1. Anatomia de um Método em Java

Um método possui um tipo de retorno (ou void quando não devolve nada), um nome (em camelCase) e uma lista de parâmetros entre parênteses.

ExemploMetodos.javavoid e com retorno
public class ExemploMetodos {

    // Método sem retorno (void)
    public static void exibirSaudacao(String nome) {
        System.out.println("Olá, " + nome + "! Bons estudos em Java.");
    }

    // Método com retorno (int)
    public static int somar(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        exibirSaudacao("Carlos");
        int resultado = somar(12, 8);
        System.out.println("Resultado da soma: " + resultado);
    }
}

Questão 09 • Prática Escreva um programa Java completo chamado CalculoArea que possua um método público e estático chamado calcularAreaRetangulo(double base, double altura) que retorne a área, e teste esse método no main.
Sugestão de implementação em Java:
Solução ExemploJava
public class CalculoArea {

    public static double calcularAreaRetangulo(double base, double altura) {
        return base * altura;
    }

    public static void main(String[] args) {
        double area = calcularAreaRetangulo(5.0, 4.0);
        System.out.println("Área do retângulo: " + area);
    }
}
Questão 10 • Prática Escreva um programa Java completo chamado VerificadorPrimo com um método público e estático boolean ehPrimo(int numero) que retorne true se o número for primo e false caso contrário. Chame-o no main.
Sugestão de implementação em Java:
Solução ExemploJava
public class VerificadorPrimo {

    public static boolean ehPrimo(int numero) {
        if (numero <= 1) {
            return false;
        }
        for (int i = 2; i <= Math.sqrt(numero); i++) {
            if (numero % i == 0) {
                return false;
            }
        }
        return true;
    }

    public static void main(String[] args) {
        int n = 17;
        System.out.println(n + " é primo? " + ehPrimo(n));
    }
}
