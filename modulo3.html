Módulo III

Estruturas Condicionais (Tomada de Decisão)

Programas inteligentes precisam escolher caminhos diferentes dependendo dos dados recebidos. Neste módulo, vamos dominar o if, else if, else e o switch-case.

Atenção: Este módulo contém 10 questões ao final (8 objetivas e 2 práticas de código).
1. Condicionais Simples, Compostas e Encadeadas

A estrutura if avalia uma expressão lógica entre parênteses. Se o resultado for true, o bloco de chaves é executado. Caso contrário, o programa segue para o else if ou else.

ClassificacaoIdade.javaif / else if / else
int idade = 20;

if (idade < 12) {
    System.out.println("Criança");
} else if (idade < 18) {
    System.out.println("Adolescente");
} else {
    System.out.println("Adulto");
}
2. Escolha Múltipla com switch-case

Quando precisamos comparar uma mesma variável contra vários valores fixos (como opções de menu ou dias da semana), o switch deixa o código muito mais limpo e legível.

DiaSemana.javaEstrutura switch
int dia = 3;

switch (dia) {
    case 1:
        System.out.println("Domingo");
        break;
    case 2:
        System.out.println("Segunda-feira");
        break;
    case 3:
        System.out.println("Terça-feira");
        break;
    default:
        System.out.println("Outro dia da semana");
        break;
}
Cuidado com Strings: Nunca compare o conteúdo de textos (String) usando ==. Use sempre texto1.equals(texto2) ou texto1.equalsIgnoreCase(texto2).

Questão 09 • Prática Escreva um programa Java completo chamado VerificadorParImpar que leia um número inteiro digitado pelo usuário e informe se ele é 'Par' ou 'Ímpar'.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class VerificadorParImpar {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Digite um número inteiro: ");
        int numero = sc.nextInt();

        if (numero % 2 == 0) {
            System.out.println("O número " + numero + " é Par.");
        } else {
            System.out.println("O número " + numero + " é Ímpar.");
        }

        sc.close();
    }
}
Questão 10 • Prática Escreva um programa Java completo chamado MenuBebidas que leia um número de 1 a 3 e, usando switch-case, imprima: 1 - 'Café', 2 - 'Chá', 3 - 'Suco Natural', ou 'Opção inválida' para outros valores.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class MenuBebidas {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Escolha uma opção (1-Café, 2-Chá, 3-Suco): ");
        int opcao = sc.nextInt();

        switch (opcao) {
            case 1:
                System.out.println("Café");
                break;
            case 2:
                System.out.println("Chá");
                break;
            case 3:
                System.out.println("Suco Natural");
                break;
            default:
                System.out.println("Opção inválida");
                break;
        }

        sc.close();
    }
}
