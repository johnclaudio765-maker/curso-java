Variáveis, Tipos Primitivos e Entrada de Dados

Para resolver problemas reais, nossos programas precisam guardar informações na memória e interagir com quem está usando o sistema. Vamos aprender a criar variáveis, realizar cálculos e capturar dados do teclado.

Atenção: Este módulo contém 10 questões ao final (8 objetivas e 2 práticas de código).
1. Variáveis e Tipos Primitivos

Imagine uma variável como uma caixinha etiquetada na memória RAM do computador. Em Java, somos obrigados a dizer qual tipo de dado cabe dentro de cada caixinha antes de usá-la.

Tabela 3 — Principais Tipos de Dados em Java

2. Operadores Aritméticos, Relacionais e Lógicos
  • Aritméticos: + (soma), - (subtração), * (multiplicação), / (divisão) e % (resto da divisão ou módulo).
  • Relacionais: == (igual), != (diferente), > (maior), < (menor), >= (maior ou igual), <= (menor ou igual).
  • Lógicos: && (E lógico), || (OU lógico), ! (NÃO / negação).
3. Lendo Dados do Teclado com Scanner

Para ler o que o usuário digita, importamos a classe java.util.Scanner no topo do arquivo e criamos um leitor ligado à entrada padrão (System.in).

CadastroSimples.javaEntrada e Saída
import java.util.Scanner;

public class CadastroSimples {
    public static void main(String[] args) {
        Scanner leitor = new Scanner(System.in);

        System.out.print("Digite seu nome: ");
        String nome = leitor.nextLine();

        System.out.print("Digite sua idade: ");
        int idade = leitor.nextInt();

        System.out.println("Olá, " + nome + "! Você tem " + idade + " anos.");
        leitor.close();
    }
}

Questão 09 • Prática Escreva um programa Java completo chamado CalculadoraMedia que leia duas notas decimais (double) digitadas pelo usuário via Scanner, calcule a média aritmética e exiba o resultado.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class CalculadoraMedia {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Digite a primeira nota: ");
        double nota1 = sc.nextDouble();

        System.out.print("Digite a segunda nota: ");
        double nota2 = sc.nextDouble();

        double media = (nota1 + nota2) / 2.0;
        System.out.println("Média final: " + media);

        sc.close();
    }
}
Questão 10 • Prática Escreva um programa Java completo chamado ConversorTemperatura que leia uma temperatura em graus Celsius e exiba o valor equivalente em Fahrenheit usando a fórmula: F = (C * 9 / 5) + 32.
Sugestão de implementação em Java:
Solução ExemploJava
import java.util.Scanner;

public class ConversorTemperatura {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Temperatura em Celsius: ");
        double celsius = sc.nextDouble();

        double fahrenheit = (celsius * 9.0 / 5.0) + 32.0;
        System.out.println("Temperatura em Fahrenheit: " + fahrenheit);

        sc.close();
    }
}
